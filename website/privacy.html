Privacy Policy

Last updated: July 28, 2026

Data Collection

Souji does not collect, transmit, or store any personal data. The application has no telemetry, no analytics, no crash reporting, and makes no network connections. It works entirely offline.

Full Disk Access

Souji requires Full Disk Access to read locations that macOS hides from applications by default — including Mail downloads, Safari data, and protected app containers. This permission is requested on first launch and is used only to scan for junk and orphaned files. No data is read beyond what is needed for cleanup. No data leaves your device.

Data Storage

Souji stores only local preferences (language selection, excluded folders, scheduling preferences) in UserDefaults on your device. No data is synced to any server or cloud service.

Third-Party Services

Souji uses Sparkle for automatic software updates. Sparkle checks for updates by making a single HTTPS request to GitHub Releases. The update check is optional and can be disabled in Settings. No usage data is transmitted.

Deletion Safety

All files removed by Souji are moved to the Trash via macOS system APIs. No files are permanently deleted without going through the Trash first. You can review every item before removal.

Changes

If this policy changes, the updated date at the top of this page will be revised. Since Souji is open source (MIT), you can verify every claim in this policy by reading the source code.

Contact

For questions about this policy, open an issue on GitHub.
