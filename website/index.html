Install Souji

Two ways to get started. macOS 13 (Ventura) or later required.

1
Homebrew (recommended):
Run brew install --cask souji in your terminal, then open Souji from your Applications folder.
2
Manual download:
Grab the latest .dmg from here, mount it, and drag Souji into /Applications.
3
Grant Full Disk Access:
Souji guides you through granting FDA on first launch. Without it, cleanup is limited — with it, Souji finds 70% more junk and uninstalls apps completely.

Our Promise

A Mac cleaner asks for the deepest permission macOS grants. Here's what we commit to.

✓Trash, never rm. Everything goes to the Trash via FileManager.trashItem. If it was wrong, drag it back.

Frequently Asked Questions

Is Souji really free?
Yes. Souji is completely free and open source under the MIT license. There is no subscription, no trial, and no paywalled features — ever.
How is this different from CleanMyMac?
CleanMyMac costs $40+/year, is closed-source, and ships telemetry. Souji is free, MIT-licensed, open source, and has zero telemetry. The cleaning quality is comparable — Souji uses the same system APIs — but Souji is honest about purgeable space and never uses fear-based scans.
Does Souji collect any data?
No. Souji has no telemetry, no analytics, no crash reporting, and makes no network connections. It works entirely offline.
Is it safe?
Everything goes to the Trash via system APIs. You review every item before removal. High-risk system paths are hard-excluded in code. Symlink attacks are prevented by path re-resolution. The code is MIT — you can read every line.
What languages are supported?
English, Traditional Chinese (繁體中文), Japanese (日本語), and Korean (한국어). Switch in Settings → General → Language at any time.
Can I build it from source?
Yes. brew install xcodegen, then generate the project with xcodegen generate, and build with Xcode.
