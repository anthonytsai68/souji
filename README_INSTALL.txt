🇹🇼 繁體中文
由於 Souji 尚未取得 Apple 開發者簽名，首次開啟時 macOS 會阻擋。
請依照以下步驟開啟：

  1. 將 Souji 拖曳到「應用程式」資料夾
  2. 開啟「系統設定」→「隱私權與安全性」
  3. 往下捲動，找到「Souji」的阻擋訊息
  4. 按一下「強制打開」
  5. 出現確認對話框時，再按一次「強制打開」

這樣就完成了。之後再開 Souji 就不需要重複這些步驟。


🇺🇸 English
Since Souji is not yet signed by an Apple Developer certificate,
macOS will block it on first launch. Here's how to open it:

  1. Drag Souji to the Applications folder
  2. Open System Settings → Privacy & Security
  3. Scroll down until you see the blocked message for Souji
  4. Click "Open Anyway"
  5. Confirm by clicking "Open Anyway" again in the dialog

That's it. macOS won't block Souji again after this.


🇯🇵 日本語
Souji はまだ Apple Developer 署名を取得していないため、
初回起動時に macOS がブロックします。以下の手順で開いてください：

  1. Souji をアプリケーションフォルダにドラッグ
  2. システム設定 → プライバシーとセキュリティ を開く
  3. 下にスクロールして Souji のブロックメッセージを探す
  4. 「それでも開く」をクリック
  5. 確認ダイアログで再度「それでも開く」をクリック

以上で完了です。次回からはブロックされません。


🇰🇷 한국어
Souji가 아직 Apple Developer 서명을 받지 않아
macOS에서 최초 실행이 차단됩니다. 다음 단계를 따라주세요:

  1. Souji를 응용 프로그램 폴더로 드래그

  3. 아래로 스크롤하여 Souji 차단 메시지 찾기
  4. "강제 열기" 클릭
  5. 확인 대화상자에서 다시 "강제 열기" 클릭

완료되었습니다. 이후부터는 차단되지 않습니다.
